# Task T02: Research Gap Analysis & Literature Synthesis

**Category:** Research / Literature review
**Difficulty:** Hard
**Expected tokens:** ~10,000–20,000 input + ~3,000–5,000 output

## Problem Statement

Select a narrow technical subfield and produce a structured research gap analysis:

> "Identify the 3 most significant open problems in **on-device continual few-shot learning for embedded vision transformers** that prevent real-world deployment in edge robotics. For each gap: explain the current state-of-the-art, why it fails in practice, what the core bottleneck is, and rank them by realistic impact on the field if solved."

## Requirements

1. Define the problem space with enough technical precision that an ML researcher would agree on boundaries
2. Identify 3 open problems — not "more data" or "better compute" (systemic, not scientific gaps)
3. For each problem:
   - Current best approach (with paper citation if possible)
   - Specific failure mode in real-world deployment
   - Root cause (theoretical gap vs. engineering gap vs. evaluation gap)
   - Realistic impact if solved (specify which robotics applications benefit and by how much)
4. Rank by: (practical impact × 3-year solve likelihood)
5. End with one "radical" idea that is currently considered high-risk but could collapse multiple gaps at once

## Quality Bar

- Technically precise — domain expert would recognize this as a serious analysis
- No generic AI-safety or alignment framing (stay on the technical problem)
- Citations can be approximate (year + key technique is fine)
- 500–900 words
