# OneNation Governance Project

**Context:** MS-002 — real-world governance via OneNation project.

**Insight:** Governance systems need verifiable audit trails, transparent rules, and accessible participation. The core design challenge is making complex rules comprehensible to non-experts while maintaining correctness.

**Design principles:**
1. Audit everything — every vote, every delegation, every result
2. Simple participation — no account creation friction
3. Transparent counting — results reproducible from public data
4. Proportional representation — ranked-choice where possible
